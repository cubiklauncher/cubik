              Minecraft 服务器

              📖 使用说明
              1. 选目录：指定一个空文件夹作为服务器目录（如 D:\mc-server），不要用已有游戏目录。
              2. 选类型与版本：原版 Vanilla（最原味）；Paper（插件服，性能好，推荐）；Fabric（可装模组）。选好对应 MC 版本。
              3. 分配内存：小服 2G 够用，人多的服建议 4G+。拖动滑块即可，Paper 会自动应用 Aikar 调优参数。
              4. 点“创建服务器”：自动下载服务端 jar、写好 eula.txt / server.properties / start.bat。
              5. 启动/停止：点“▶ 启动服务器”开服；下方日志区可看输出；点“⏹ 停止”关服。
              6. 发指令：在下边输入框直接输服务器指令（如 op 你的名字、say hello、stop），回车即发送到后台。
              7. 联机：同一局域网用本机内网 IP + 端口（默认 25565）进入；公网联机见下方「🔌 端口映射教程」。

              提示：首次启动会生成世界，稍等片刻；开服前请确认已接受 Minecraft EULA（创建时已自动写入）。

              🚇 内网穿透（一键让外网朋友直连，不用改路由器）

              原理：用一个公网中转服务器把你的本地端口映射到公网。基于开源 frp（MIT）实现。 你需要有一个 frp 服务端地址（可自建，或用你手上的免费 frp 服务）；没账号的情况下可以用下方推荐渠道。

              推荐渠道（自行注册获取服务端地址与 token）： SakuraFrp（国内常用） · FRP 公共服 · 自建 frps（开源）

        🔌 端口映射教程（让外网朋友连上你的服务器）
        
              
        
              同一 WiFi 下直接发给朋友「局域网地址」即可，不需要这一步。只有当朋友不在你家里（用手机热点/其他地方网络）时才需要做端口映射。
              

        
              先搞清三件东西
              
        
                
          
              • 本机内网 IP：上面「🏠 局域网地址」前的部分，如 192.168.3.30（重启路由器可能变，建议在路由器里给本机绑定静态 IP）。
                • 
          
              • 端口：默认 25565（上面「🔌 端口」显示的值）。
                • 
          
              • 公网 IP：上面「🌍 公网 IP」显示的值，如 106.4.251.252。
                • 
        
              

        
              步骤一：登录路由器后台
              
        
                
          
              1. 浏览器打开路由器管理页，常见地址：192.168.1.1 或 192.168.0.1 或 tplogin.cn（路由器背面标签上写着）。
                2. 
          
              2. 输入管理员账号密码登录（默认多为 admin/admin，也印在路由器背面）。
                3. 
        
              

        
              步骤二：添加端口转发规则
              
        
                
          
              1. 找到「端口转发 / 虚拟服务器 / 端口映射 / NAT / 转发规则」这类菜单（不同品牌叫法不同，通常在「高级设置」里）。
                2. 
          
              2. 新增一条规则，填：
            
                  
              
                • 名称：Minecraft（随意）
                  • 
              
                • 外部端口 / 服务端口：25565（可改成别的，改后朋友要连新端口）
                  • 
              
                • 内部端口：25565
                  • 
              
                • 内部 IP / 主机 IP：192.168.3.30（换成上面你的内网 IP）
                  • 
              
                • 协议：选 TCP（Minecraft 用 TCP；部分路由器要求选 TCP+UDP，那也选上）
                  • 
              
                • 启用：勾上 ✅
                  • 
            
                
          
                3. 
          
              3. 保存并应用。
                4. 
        
              

        
              步骤三：把地址发给朋友
              
        
              朋友在游戏里「多人游戏 → 添加服务器 → 服务器地址」填：
              
        
              你的公网IP:端口 例如 106.4.251.252:25565
              

        
              ⚠️ 常见问题
              
        
                
          
              • 朋友连不上？先确认服务器已「▶ 启动」且日志出现 Done；再确认防火墙放行：Windows「防火墙」→「允许应用通过」里勾上 java.exe（专用 + 公用都勾）。
                • 
          
              • 公网 IP 一会儿就变？多数家庭宽带是动态公网 IP，重启光猫会变。要稳定可用 DDNS（域名解析）或内网穿透。
                • 
          
              • 根本拿不到公网 IP（电信/联通大内网）？若上面「公网 IP」是 100.64.x.x / 10.x.x.x 这类，说明你没有真公网 IP，端口映射无效。改用内网穿透（如 frp、ngrok、Sakura Frp、花生壳），或打运营商客服申请公网 IP。
                • 
          
              • 最简单方案：如果搞不定路由器，直接用内网穿透工具（如 Sakura Frp），它会给你一个公网地址，朋友直接连那个地址即可，无需路由器设置。
                • 
          
              • 只想和几个人玩：也能用玩家的「对局域网开放」+ 内网穿透，或第三方联机平台（如 网易版联机、Radmin VPN 组建虚拟局域网）。
