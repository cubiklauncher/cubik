FAQ

常见问题

使用前先看看这些，能解决大部分疑问。

启动时提示找不到 Java？
到「设置」中开启「自动下载 Java」，或手动指定已安装的 java.exe 路径。Cubik 会按游戏版本自动匹配对应的 Java。
整合包装完后在哪里启动？
整合包会作为独立实例出现在「版本选择」页，选中它点「启动游戏」即可，不同版本之间互不干扰。
内存应该分配多少？
整合包建议 4G~8G，原版 2G~4G。设置在「设置」页，滑块上方会给出基于你物理内存的建议值。
下载很慢怎么办？
确认「设置 → 下载源」选择的是「BMCLAPI 国内镜像」，国内用户建议保持此项。
检查更新提示无法验证证书？
这是部分企业网络 / 安全软件替换 TLS 证书导致的。请使用 v1.0.10 及以上版本，已内置证书兼容处理。
支持正版登录吗？
支持。使用微软正版账号登录后会自动完成 Xbox Live 验证并获取你的正版档案，支持多账号切换。
Cubik 是免费的吗？
完全免费且开源（MIT 协议）。Cubik 不包含任何游戏本体文件，仅提供下载与管理工具，请支持购买正版游戏。
ABOUT

关于 Cubik

Cubik 是一款独立的第三方开源 Minecraft 启动器，致力于让「下载游戏、装整合包、开服务器」这些事变得简单。

它不包含任何游戏本体文件，仅提供下载与管理工具。界面清爽、启动快、国内加速，适合从新手到老玩家的各类用户。
